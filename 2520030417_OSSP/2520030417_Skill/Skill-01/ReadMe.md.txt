# Skill 1: Process Management and System Calls

## Objective
To understand process creation and execution in Linux by implementing `fork()`, `exec()`, and `wait()` system calls, and investigating system hardware mapping.

## Project Structure
* SRC/Skill-01.c - Source code for process creation and execution.
* OUTPUTS/process_output.txt - Execution logs showing parent-child coordination.
* OUTPUTS/lscpu_output.txt - CPU specification details.
* OUTPUTS/lsblk_output.txt - Storage block device details.
* ReadMe.md - Documentation.
