# practical_02: Low-Level File I/O and System Call Tracing

## Objective
1. Develop a C program using open(), read(), write(), and close() to copy file contents and explain user/kernel space control transitions.
2. Use the strace utility to trace system calls generated by cat sample.txt` and identify kernel services.

## User Space to Kernel Space Transition
* **User Mode:** Applications run with restricted hardware access.
* **System Call Trap:** When a call like open() or read() is executed, a trap switches the CPU into Kernel Mode.
* **Kernel Execution:** The kernel safely handles the file operation and returns control back to user space.

## strace Analysis Summary
The trace log in OUTPUTS/strace_log.txt shows the sequence of system calls (openat, read, write, close) used by cat to read and display file contents.
